Thao tác API

Xác thực và hạn mức

Thao tác ghi luôn cần JWT. Chỉ bật đọc công khai cho dữ liệu thực sự công khai.

Ánh xạ sẽ tạo

GET đọc; POST tạo mới; PUT thay toàn bộ; PATCH cập nhật một phần; DELETE xóa. Gateway ánh xạ request tới backend. Backend quyết định response và mã thành công.
